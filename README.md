# 칭찬스티커판 👑

아이가 좋아하는 주제로 만든 칭찬 스티커판 웹앱입니다.

🔗 공주판 https://yoonminimini1.github.io/mimi-princess-sticker/
🚗 자동차판 https://yoonminimini1.github.io/mimi-princess-sticker/car/

## 쓰는 법
- 할 일(미션)을 하나 해내면 스티커를 한 칸 붙여요.
- 정해 둔 칸을 다 채우면 보상이 열려요.
- 기록은 그 기기의 브라우저에 저장돼요.

## 파일
- `index.html` — 공주 스티커판 (이미지·아이콘 모두 안에 들어 있어 이 파일 하나로 동작해요)
- `car/index.html` — 자동차 스티커판 (같은 방식, 기록은 따로 저장돼요)
